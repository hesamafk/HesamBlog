About me.

Learning the craft, one project at a time.

I'm Hesam Afkhami, a Computer Engineering student focused on Software Engineering. I'm interested in building for the web and understanding how interfaces, application logic, and data work together.

My learning toolkit includes HTML, CSS, JavaScript, PHP, Git, and GitHub. I treat each project as an opportunity to practice fundamentals, improve my problem-solving, and learn to ship more carefully.

This website is a small public notebook for that process. It highlights learning notes and project experiments; it is not intended to overstate experience or imply that every idea here is production-ready.
