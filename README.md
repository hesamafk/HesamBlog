# HesamBlog — Personal Portfolio (Demo)

Static personal website and technical blog prototype, intended for portfolio and learning purposes.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Blog (`blog.html`)
- Contact (`contact.html`)
- Two example posts (`posts/`)

## Limitations
This is a static demo with no CMS or backend. Contact is email-based, not a server-side form.

## Source
The full project is supplied separately as `HesamBlog-Portfolio-Ready.zip`. Its HTML, CSS and JavaScript source has not yet been committed to this repository.
