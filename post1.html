LEARNING NOTES · 4 MIN READ

Starting my web development journey

Learning web development is less about memorizing every tag and more about getting comfortable with building, breaking, and improving small things.

THE BEGINNING{ }

Start with the foundations

HTML gives a page structure, CSS shapes its presentation, and JavaScript adds behavior. Learning how these pieces work together makes debugging less mysterious and gives each new feature a clear place to live.

Make projects small enough to finish

A tiny landing page, a responsive navigation menu, or a simple filterable list can teach more than a large project that never reaches a working state. Finishing creates a feedback loop: build, inspect, fix, and try again.

Keep a record of what changed

Version control makes experiments safer. A useful commit explains the intention behind a change, and a README helps another person understand how to run the project and what still needs work.

Measure progress honestly

Every project has limits. Calling out placeholder content, untested behavior, and missing backend services is part of good engineering—not a weakness. The next step becomes clearer when the current state is documented accurately.

This article is a personal learning reflection and will evolve as I gain more experience.
