TOOLS & WORKFLOW · 5 MIN READ

Tools that help me learn and build

A useful workflow does not need dozens of apps. It needs a few dependable tools and habits that make the work easier to understand.

MY TOOLKIT⌘

A code editor

A good editor helps navigate files, spot syntax mistakes, and keep related code organized. Extensions can help, but I try to understand the underlying problem before adding another tool.

The browser developer tools

The browser is both the place where the interface runs and a powerful debugging environment. Inspecting layout, checking the console, and testing different viewport sizes catch issues early.

Git and GitHub

Git records changes locally; GitHub makes repositories easier to share, review, and connect to automated checks. Small, focused commits and a clear README make a project easier to maintain.

A repeatable checklist

  • Open the project from a clean checkout.
  • Follow the documented setup steps.
  • Test the main navigation and interactions.
  • Check responsive layouts and the browser console.
  • Write down known limitations instead of hiding them.

Tools change over time. The habit of understanding, testing, and documenting work lasts much longer.
